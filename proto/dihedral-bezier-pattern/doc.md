# 二面体群ベジェパターン生成プロトタイプ

## 概要

鏡映を含む合同変換群の対称性をもつ模様を、ランダムな輪郭から生成するアルゴリズムのプロトタイプ。

基本領域（fundamental domain）にだけランダムな模様を描き、群の変換すべてでコピーすることで、全体として狙った対称性をもつ模様を作る。

3 つの版を用意する。**構図・配色のルールは 3 版で共通で、対称性の種類と模様の描き方だけが違う。**

| 版 | スクリプト | 対称性 | 描き方 |
| --- | --- | --- | --- |
| 曲線版 | `src/generate.js` | 二面体群 D_n | 制御点がランダムな 3 次ベジェ曲線 |
| 直線版（角ばった版） | `src/generate-angular.js` | 二面体群 D_n | 折れ線・多角形のみ（曲線を使わない） |
| 壁紙群版 | `src/generate-wallpaper.js` | 壁紙群 17 種すべて | 基本領域の塗り分けと、向きのわかる非対称な印 |

はじめの 2 版は 1 個のロゼッタ模様（メダリオン）を作る。壁紙群版は、平面を埋めつくす繰り返し模様を作り、**17 の壁紙群を同じモチーフで並べて見比べられるようにする**のが目的。

## 技術スタック

- 依存パッケージなしの素の JavaScript（ESM）で実装する
- `node src/generate.js` / `node src/generate-angular.js` / `node src/generate-wallpaper.js` で実行することで、SVG ファイルが生成されるようにする
- SVG は文字列として直接組み立てる

## 数学的な下敷き

### 二面体群 D_n

正 n 角形を自分自身に重ねる合同変換は 2n 個ある。

- 回転 `r^k`（k = 0..n-1）：中心まわりに 360k/n 度
- 鏡映 `r^k · m`（k = 0..n-1）：鏡映してから回転

### 基本領域

正 n 角形の中心 O・辺の中点 M・頂点 V が作る直角三角形 △OMV が基本領域になる。2n 個のコピーで正 n 角形をちょうど覆う。

α = π/n として、内接円半径（アポテム）を a とすると

- O = (0, 0)
- M = (a, 0) … 角度 θ = 0 の方向
- V = (a, a·tan α) … 角度 θ = α の方向

θ = 0 と θ = α の 2 本の半直線が鏡映線であり、この 2 枚の鏡が D_n 全体を生成する。

### 鏡映線での滑らかな接続

基本領域を θ=0 から θ=α まで横断する曲線の両端で、**接線を鏡映線に直交させる**と、その曲線と鏡像が端点で滑らかにつながる。結果として 2n 個のコピー全体が 1 本の閉じた波打つ環になる。

曲線版の帯（band）とリボン（ribbon）はこの性質を使っている。

- θ=0 側の端点の接線方向：`(0, 1)`
- θ=α 側の端点の接線方向：`(-sin α, cos α)`

直線版ではこの制約を外し、鏡映線の上で角が立つのをそのまま活かして星形・鋸歯にしている。

### 壁紙群

平面を埋めつくす繰り返し模様の対称性は、17 種類しかない（壁紙群・平面群）。どの群も

- 2 方向の平行移動（格子）
- 回転（2・3・4・6 回のいずれか）
- 鏡映
- すべり鏡映（鏡に映してから、その鏡に沿って半周期ずらす）

の組み合わせでできている。格子の種類（斜方・長方・面心長方・正方・六方）と、単位格子 1 枚を埋める変換の集まりが群を決める。

| 群 | 格子 | 点群 | 単位格子あたりの変換 |
| --- | --- | --- | --- |
| p1 | 斜方 | 1 | 1 |
| p2 | 斜方 | 2 | 2 |
| pm / pg | 長方 | m | 2 |
| cm | 面心長方 | m | 4 |
| pmm / pmg / pgg | 長方 | 2mm | 4 |
| cmm | 面心長方 | 2mm | 8 |
| p4 | 正方 | 4 | 4 |
| p4m / p4g | 正方 | 4mm | 8 |
| p3 | 六方 | 3 | 3 |
| p3m1 / p31m | 六方 | 3m | 6 |
| p6 | 六方 | 6 | 6 |
| p6m | 六方 | 6mm | 12 |

同じ点群でも、鏡が純粋な鏡かすべり鏡かで別の群になる（pm と pg、pmm と pmg と pgg、p4m と p4g）。また p3m1 と p31m は鏡の向きが違い、**3 回回転の中心がすべて鏡の上に乗るのが p3m1、一部が鏡から外れるのが p31m**。

### 変換は格子座標で書く

変換は、基本並進ベクトル t1・t2 を基底にした格子座標で定義する。この座標なら回転も鏡映も整数行列になり、並進は 1/2 の分数だけで済むので、17 群を誤差なしに書き下せる。描画のときだけ基底行列 P = [t1 t2] を使って Cartesian に直す。

- 行列：`A = P · M · P⁻¹`
- 並進：`c = P · t`

変換の一覧は生成元からの閉包で作る。手で数え上げると取りこぼすうえ、閉包なら「変換の数が点群の位数と合うか」で誤りに気づける。

### 基本領域はディリクレ領域として求める

17 群ぶんの基本領域を手で書き下すかわりに、**ボロノイ領域として計算する**。

どの変換でも動かない点（回転中心・鏡の上）を避けた一般の位置の点 b をひとつ選ぶと、b の軌道には重なりがない。そのとき「軌道の中で b がいちばん近い点の集まり」は必ず正しい基本領域になる。この作り方には利点がある。

- **凸多角形になる**ので、中心から放射状に切り分ければ領域を過不足なく塗り分けられ、内接円をとれば模様を領域内に収められる
- **面積がちょうど「単位格子 ÷ 変換の数」になる**ので、正しさを数値で検算できる
- **17 群を同じコードで扱える**（群ごとの場合分けが要らない）

b は「内接円と外接円の比がいちばん 1 に近くなる（＝いちばん丸い）位置」を格子内から総当たりで選ぶ。細長い基本領域だと模様が置きにくく、群どうしの見比べもしにくいため。

## 実装要件

- 正方形の SVG 画像として生成する（既定 480px 四方）
- ランダム性は seed 付き PRNG（mulberry32）で制御し、同じ seed からは同じ模様が再現される
- **色数 2〜6 のパターンを一度の実行で一括生成する**
- **`--n` は範囲指定できる。** `--n=4,24` なら n = 4〜24 の全てを一度に生成し、出力先も一覧 HTML も 1 つにまとめる
- n を範囲で生成するとき、**seed に n を混ぜない。** 同じ色数なら n が変わっても帯の構成と配色がそろい、対称性の次数だけを見比べられる（基本領域の広さで要素の採否が変わるため、細部のアクセントは多少ずれる）
- **壁紙群版は 17 群を一度の実行で一括生成する**（`--group` で絞れる）
- 壁紙群版も同じ理由で、**seed に群を混ぜない。** 17 群で区画の構成と配色がそろい、対称性の違いだけを見比べられる
- **群をまたいで「基本領域」の面積をそろえる**（単位格子ではなく）。こうするとどの群でもモチーフが同じ大きさで現れ、並べ方の違いだけを見比べられる。単位格子の大きさは群ごとに変わる（p6m は p1 の 12 倍）
- **背景は白（`#FFFFFF`）で固定し、パレットの色は背景に使わない。** パレットの k 色はすべて模様の側で使う
- 色は「インデックスが小さいほど使用面積が大きい」順に並べる。壁紙群版は基本領域を細かくサンプルして、上に重ねた要素に隠れたぶんを除いた実際の使用面積を数える。最後にその順で色を並べ替えて、この順序を確定させる
- パレットに含まれる色は必ず 1 回以上使う。壁紙群版では「重ねた要素に完全に隠れて見えなくなった色」も取りこぼしとして扱い、点を置いて補う
- 既定パレットは 1 本のマスターリストの先頭 k 色。色数を増やしても色が入れ替わらないので、色数どうしを比較できる
- 生成した SVG は `.generated/{curved|angular}/{YYYYMMDD-THHMMSSZ}/d{n}-{k}colors.svg` に出力する。壁紙群版は `.generated/wallpaper/{YYYYMMDD-THHMMSSZ}/{群名}-{k}colors.svg`
- 同じディレクトリに、生成物を並べて見るための `index.html` も出力する。n を範囲で生成したときは n ごとに、壁紙群版は色数ごとに節を分ける（節の中に 17 群が並ぶので、群どうしを見比べられる）
- 壁紙群版は、`--guide` を付けなくても一覧の先頭に**群ごとの解説図**（対称性の要素を重ねたもの）を 1 枚ずつ並べる
- コンソールには生成した SVG ファイルへのパスと、生成にかかった時間を出力する（枚数が多いときはパスの代わりに件数を出す）

## ロゼッタ版が基本領域に描く要素

すべて `(level, θ)` の座標で位置を決める。level は「その角度における基本領域の外周までの距離」を 1 とした比率で、正 n 角形（または円）の輪郭に沿ってスケールされる。

| 要素 | 曲線版 | 直線版 |
| --- | --- | --- |
| band | 2 本のレベル曲線に挟まれた帯。面積を担う主要素。中心から外周までを 3〜8 本に分割する | 同じ。境界が鋸歯または階段状の折れ線になる |
| ribbon | レベル曲線をストロークした細い環 | 折れ線をストロークした細い環 |
| spoke | 半径方向にしなった曲線のストローク | まっすぐな放射線 |
| petal | 中心から外へ伸びる葉状の閉曲線 | 中心から外へ伸びる凧形 |
| shard | （なし） | 領域内のランダムな三角形 |
| blob | 領域内に収まるランダムな閉曲線 | 領域内に収まるランダムな多角形 |
| dot | 小さな円 | 小さな正方形・菱形 |
| center | 中心の円（不動点なのでコピーせず 1 個だけ描く） | 中心の正 n 角形 |

輪郭の作り方だけが 2 つの版の違い。

- **曲線版**：θ を 4 点サンプリングして level をランダムに揺らし、Catmull-Rom 的な接線から 3 次ベジェに変換する。両端の接線だけは前述のとおり鏡映線に直交するよう固定する
- **直線版**：θ を 5〜10 点サンプリングし、level の揺らぎの符号を交互にして規則的な鋸歯にする。歯の数はすべての帯で共通なので、同心のジグザグとして読める。3 割の確率で「level を保ったまま θ を進めてから半径方向へ動く」階段状になり、城壁のような凹凸になる

## 壁紙群版が基本領域に描く要素

17 群を見比べるのが目的なので、どの群でも同じ組み立て方をする。

| 要素 | 内容 |
| --- | --- |
| sector（地の塗り分け） | 基本領域を中心から放射状に 3〜7 枚に切り分けて塗る。多角形を過不足なく覆うので、コピーすると平面が塗り残しなく埋まる |
| ring（入れ子の輪） | 5 割強の確率で、中心に基本領域の相似形を 1〜2 枚重ねる |
| mark（非対称な印） | 向きのわかる F 字を中心に置く。基本領域の内接円に収める |
| dot（補いの点） | 上に重ねた要素に隠れて見えなくなった色があれば、その色の点を置いて補う |

区画の色は、ロゼッタ版と共通の帯のルール（幅の比を 0.6〜1.8 に収め、隣り合う区画を別の色にする）で決める。輪と印の色は共通の `accentColor`（下地と同色を避け、面積を小さく保ちたい色を優先する）で決める。

**印が非対称であることが肝心。** これがないと、となりのコピーが回転なのか鏡映なのかすべり鏡映なのかが見分けられず、群を比べる意味が薄れる。F 字は上下も左右も対称でないので、向きだけで対称操作が読み取れる。

### 対称性の要素（`--guide`）

比較の助けとして、模様の上に対称性の要素を重ねられる。

| 表示 | 意味 |
| --- | --- |
| 実線の平行四辺形 | 単位格子 |
| 細かい破線の多角形 | 基本領域（群の変換ぶんを敷き詰めたもの） |
| 太い実線 | 鏡 |
| 破線 | すべり鏡 |
| レンズ・三角・四角・六角 | 回転中心（2・3・4・6 回） |

回転中心は変換の不動点 `x = (I − A)⁻¹·c` として、鏡とすべり鏡は鏡映変換の並進を鏡に平行な成分と垂直な成分に分けて求める。**平行な成分が 0 なら純粋な鏡、残れば すべり鏡**。同じ軸に両方が乗るときは鏡として扱う。

## 設計上の判断

- **クリップしない**：基本領域でクリップすると、隣り合うコピーの境界にアンチエイリアスの継ぎ目（2n 本の放射状の線）が出る。代わりに各要素が基本領域の内側に収まるよう生成時に制約する。ストロークは半分だけ鏡映線をまたぐが、鏡像と重なるので問題にならない
- **塗りにヘアライン**：帯の塗りには同色の `stroke-width: 0.7` を足し、コピー間の継ぎ目を消す
- **アクセントのレベル上限**：最外周の帯が最も内側へ凹むレベルを上限にする。これを超えると、線や点が模様の輪郭の外へ飛び出して見える
- **階段状の最後の段差は潰す**：θ=α の鏡映線にちょうど重なり、帯が幅ゼロの針になる。塗りには出ないのにヘアラインだけが線として見えてしまう
- **`<use>` によるコピー**：基本領域の模様を `<defs>` 内の `<g>` として 1 度だけ定義し、2n 個の `<use>` で変換配置する。壁紙群版は 3 段構えで、基本領域 → 群の変換で単位格子 1 枚 → 平行移動で敷き詰め、と `<use>` を重ねる
- **単位格子はキャンバスの中心に合わせて敷く**：キャンバスの中心に単位格子の中心を置き、外側は 2 枚ぶん多めに敷いて viewport で切る。基本領域は単位格子の外へはみ出しうるので、1 枚ぶんの余裕では縁が欠けることがある
- **面積の順序は最後に確定させる**：基本領域をサンプルすれば実際に見えている面積を数えられるので、配色の重み付けに任せず、最後に使用面積の大きい順へ色を並べ替える。色の入れ替えなので、隣り合う区画やアクセントと下地が同色にならない性質は保たれる
- **隠れて消えた色も取りこぼしとして扱う**：入れ子の輪や印が下の要素を覆いきってしまうことがある。要素を数えるだけでは気づけないので、上から見えている面積で判定する

## 使い方

オプションはロゼッタの 2 つのスクリプトで共通。

```bash
node src/generate.js                       # 曲線版・色数 2〜6 を一括生成
node src/generate-angular.js               # 直線版・色数 2〜6 を一括生成

node src/generate.js --n=9                 # 正九角形の対称性
node src/generate.js --n=4,24              # n = 4〜24 を範囲で一括生成（--n=4-24 も可）
node src/generate.js --seed=12345          # 再現可能な生成
node src/generate.js --count=3             # 色数ごとに 3 種類ずつ
node src/generate.js --shape=circle        # 正 n 角形ではなく円形に収める
node src/generate.js --size=800            # 出力サイズ
node src/generate.js --colors='#fff,#123'  # パレットを指定（その色数のみ生成）
node src/generate.js --help                # ヘルプ
```

壁紙群版は `--n` と `--shape` のかわりに、群と敷き詰めの細かさを指定する。

```bash
node src/generate-wallpaper.js                    # 17 群 × 色数 2〜6 を一括生成
node src/generate-wallpaper.js --group=p6m,p4g    # 群を絞る
node src/generate-wallpaper.js --repeat=8         # キャンバスの横幅あたりの基本領域の枚数
node src/generate-wallpaper.js --guide            # すべての出力に対称性の要素を重ねる
node src/generate-wallpaper.js --help             # ヘルプ
```

`--seed` `--count` `--size` `--colors` `--out` は 3 つのスクリプトで共通。
