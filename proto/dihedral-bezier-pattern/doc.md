# 二面体群ベジェパターン生成プロトタイプ

## 概要

鏡映を含む合同変換群の対称性をもつ模様を、ランダムな輪郭から生成するアルゴリズムのプロトタイプ。

基本領域（fundamental domain）にだけランダムな模様を描き、群の変換すべてでコピーすることで、全体として狙った対称性をもつ模様を作る。

複数の版を用意する。**構図・配色のルールは全版で共通で、対称性の種類と模様の描き方だけが違う。**

| 版 | スクリプト | 対称性 | 描き方 |
| --- | --- | --- | --- |
| 曲線版 | `src/generate.js` | 二面体群 D_n | 制御点がランダムな 3 次ベジェ曲線 |
| 直線版（角ばった版） | `src/generate-angular.js` | 二面体群 D_n | 折れ線・多角形のみ（曲線を使わない） |
| 壁紙群版 | `src/generate-wallpaper.js` | 壁紙群 17 種すべて | 基本領域の塗り分け（非対称な印は `--mark` のときだけ） |
| 壁紙群・丸み版 | `src/generate-wallpaper-round.js` | 壁紙群 17 種すべて | 丸い図形の組み合わせ（非対称な印は既定であり） |
| ペンローズ版 | `src/generate-penrose.js` | 非周期（5 回対称は 1 点だけ） | 4 種のタイルの置換 |
| カイト＆ダート版 | `src/generate-kite-dart.js` | 非周期（5 回対称は 1 点だけ） | 2 種のタイルの分割 |
| 準結晶版 | `src/generate-crystal.js` | 非周期（結晶核のまわりだけ 5 回対称） | カイト＆ダートを結晶標本として重ね描き |

はじめの 2 版は 1 個のロゼッタ模様（メダリオン）を作る。壁紙群版は、平面を埋めつくす繰り返し模様を作る。**17 の壁紙群を同じモチーフで並べられる**ので群どうしの見比べにも使えるが、直線版（`generate-wallpaper.js`）が主に狙うのは**模様として見て美しい直線的な幾何パターン**を作ること。対称操作の見分けに使う非対称な印は、観察したいときだけ `--mark` で足す。

**あとの 2 版（ペンローズ版・カイト＆ダート版）は基本領域を持たない。** 平行移動の周期がないタイリングなので、基本領域を群の変換でコピーするのではなく、タイルを縮めて置き換える規則を繰り返して平面を埋める。共通なのは「色数 2〜6 の一括生成」「背景は白」「色はインデックスが小さいほど使用面積が大きい」といった配色まわりのルール。

ペンローズのタイリングは 2 通り作る。**P1（五角形版）** は正五角形・星・舟・菱形の 4 種、**P2（カイト＆ダート版）** は凧形と矢じり形の 2 種。タイルの形は違うが、一方の線を引き直せばもう一方が得られる同じ族のタイリングで、どちらも黄金比 φ を軸にした自己相似な入れ子構造を持つ。

**準結晶版はカイト＆ダート版と同じタイリングを使い、見せ方だけを変えた版。** タイルを塗り分けるのではなく、結晶核・結晶面・劈開線・頂点ネットワーク・回折像を重ねて、**数学的には準周期構造なのに、視覚的には未知の鉱物の標本に見えるもの**を作る。タイリングそのものは `kite-dart-geometry.js` をそのまま使うので、カイト＆ダート版とは「同じ結晶を別の方法で観察した絵」の関係になる。

## 技術スタック

- 依存パッケージなしの素の JavaScript（ESM）で実装する
- `node src/generate.js` / `node src/generate-angular.js` / `node src/generate-wallpaper.js` で実行することで、SVG ファイルが生成されるようにする
- SVG は文字列として直接組み立てる

## 数学的な下敷き

### 二面体群 D_n

正 n 角形を自分自身に重ねる合同変換は 2n 個ある。

- 回転 `r^k`（k = 0..n-1）：中心まわりに 360k/n 度
- 鏡映 `r^k · m`（k = 0..n-1）：鏡映してから回転

### 基本領域

正 n 角形の中心 O・辺の中点 M・頂点 V が作る直角三角形 △OMV が基本領域になる。2n 個のコピーで正 n 角形をちょうど覆う。

α = π/n として、内接円半径（アポテム）を a とすると

- O = (0, 0)
- M = (a, 0) … 角度 θ = 0 の方向
- V = (a, a·tan α) … 角度 θ = α の方向

θ = 0 と θ = α の 2 本の半直線が鏡映線であり、この 2 枚の鏡が D_n 全体を生成する。

### 鏡映線での滑らかな接続

基本領域を θ=0 から θ=α まで横断する曲線の両端で、**接線を鏡映線に直交させる**と、その曲線と鏡像が端点で滑らかにつながる。結果として 2n 個のコピー全体が 1 本の閉じた波打つ環になる。

曲線版の帯（band）とリボン（ribbon）はこの性質を使っている。

- θ=0 側の端点の接線方向：`(0, 1)`
- θ=α 側の端点の接線方向：`(-sin α, cos α)`

直線版ではこの制約を外し、鏡映線の上で角が立つのをそのまま活かして星形・鋸歯にしている。

### 壁紙群

平面を埋めつくす繰り返し模様の対称性は、17 種類しかない（壁紙群・平面群）。どの群も

- 2 方向の平行移動（格子）
- 回転（2・3・4・6 回のいずれか）
- 鏡映
- すべり鏡映（鏡に映してから、その鏡に沿って半周期ずらす）

の組み合わせでできている。格子の種類（斜方・長方・面心長方・正方・六方）と、単位格子 1 枚を埋める変換の集まりが群を決める。

| 群 | 格子 | 点群 | 単位格子あたりの変換 |
| --- | --- | --- | --- |
| p1 | 斜方 | 1 | 1 |
| p2 | 斜方 | 2 | 2 |
| pm / pg | 長方 | m | 2 |
| cm | 面心長方 | m | 4 |
| pmm / pmg / pgg | 長方 | 2mm | 4 |
| cmm | 面心長方 | 2mm | 8 |
| p4 | 正方 | 4 | 4 |
| p4m / p4g | 正方 | 4mm | 8 |
| p3 | 六方 | 3 | 3 |
| p3m1 / p31m | 六方 | 3m | 6 |
| p6 | 六方 | 6 | 6 |
| p6m | 六方 | 6mm | 12 |

同じ点群でも、鏡が純粋な鏡かすべり鏡かで別の群になる（pm と pg、pmm と pmg と pgg、p4m と p4g）。また p3m1 と p31m は鏡の向きが違い、**3 回回転の中心がすべて鏡の上に乗るのが p3m1、一部が鏡から外れるのが p31m**。

### 変換は格子座標で書く

変換は、基本並進ベクトル t1・t2 を基底にした格子座標で定義する。この座標なら回転も鏡映も整数行列になり、並進は 1/2 の分数だけで済むので、17 群を誤差なしに書き下せる。描画のときだけ基底行列 P = [t1 t2] を使って Cartesian に直す。

- 行列：`A = P · M · P⁻¹`
- 並進：`c = P · t`

変換の一覧は生成元からの閉包で作る。手で数え上げると取りこぼすうえ、閉包なら「変換の数が点群の位数と合うか」で誤りに気づける。

### 基本領域はディリクレ領域として求める

17 群ぶんの基本領域を手で書き下すかわりに、**ボロノイ領域として計算する**。

どの変換でも動かない点（回転中心・鏡の上）を避けた一般の位置の点 b をひとつ選ぶと、b の軌道には重なりがない。そのとき「軌道の中で b がいちばん近い点の集まり」は必ず正しい基本領域になる。この作り方には利点がある。

- **凸多角形になる**ので、中心から放射状に切り分ければ領域を過不足なく塗り分けられ、内接円をとれば模様を領域内に収められる
- **面積がちょうど「単位格子 ÷ 変換の数」になる**ので、正しさを数値で検算できる
- **17 群を同じコードで扱える**（群ごとの場合分けが要らない）

b は「内接円と外接円の比がいちばん 1 に近くなる（＝いちばん丸い）位置」を格子内から総当たりで選ぶ。細長い基本領域だと模様が置きにくく、群どうしの見比べもしにくいため。

### 五角形ペンローズタイリング（P1）

ペンローズが最初に見つけたタイリング。**正五角形・星（五芒星）・舟・菱形**の 4 種で平面を非周期に埋める。4 種とも辺の長さは等しい。

平行移動の周期は取れないが、どんな有限の並びも別の場所に何度でも現れる。5 回対称の中心は全体で 1 点だけ。

**置換（inflation）で作る。** 各タイルを 1/φ² に縮めた同じ 4 種の集まりで置き換える操作を繰り返す（φ は黄金比）。

| もとのタイル | 置き換わる先 |
| --- | --- |
| 五角形 | 五角形 6 枚（中心 1 枚 + 頂点側 5 枚）と、5 つの辺に半分ずつはみ出す菱形 |
| 星 | 36 度回した星 1 枚と、とがりの向きに五角形 5 枚・舟 5 枚 |
| 舟 | 星と同じ規則の 3 方向ぶん（舟は星のとがり 3 つぶんの形なので） |
| 菱形 | 矢印の側に寄った五角形 1 枚、その先に舟、反対のとがりに星 |

**正五角形が 6 枚の正五角形に分かれ、細い三角形が 5 つだけ残る**（残りが菱形の半分になる）というのがこのタイリングの出発点。

**置換で生まれるタイルは親の輪郭からはみ出す。** はみ出した先では隣のタイルが同じタイルを生むので、位置と向きが一致するものを 1 枚にまとめれば、隙間も重なりもなく埋まる。

**菱形には向き（矢印）がある。** 置換すると五角形が長い対角線に沿って片側に寄るので、どちらのとがりへ寄せるかを決めないといけない。菱形は必ず 2 枚の五角形の間にでき、辺で接する正五角形どうしは必ず 36 度ずれているので、**「向きが 2 種類あるうちの決めたほうの五角形から外を向く」と決めれば矢印が一意に定まる**。

**五角形は 5 辺すべてに菱形を出すが、辺の向こうが星や舟ならその隙間は星や舟が埋める。** 星・舟と重なる菱形は落とす。

### カイト＆ダートタイリング（P2）

ペンローズのタイリングをいちばん少ない種類のタイルで表したもの。**カイト（凧形）とダート（矢じり形）**の 2 種で、辺の長さはどちらも短辺 1・長辺 φ の 2 種類しかない。

| タイル | 内角 | 辺 |
| --- | --- | --- |
| カイト | 72-72-72-144（凸） | 長辺 φ・φ、短辺 1・1 |
| ダート | 36-216-36-72（へこむ） | 短辺 1・1、長辺 φ・φ |

**半分に切ると二等辺三角形（ロビンソン三角形）になる。** カイトの半分は頂角 36 度・等辺 φ・底辺 1 の鋭角三角形、ダートの半分は頂角 108 度・等辺 1・底辺 φ の鈍角三角形。**分割規則はこの半タイルの上で書く**（カイトやダートのままでは書けない）。

| もとの半タイル | 分割される先 |
| --- | --- |
| 半カイト | 半カイト 2 枚 + 半ダート 1 枚 |
| 半ダート | 半カイト 1 枚 + 半ダート 1 枚 |

タイル 1 枚ぶんで言えば「カイト → カイト 2 枚 + 半ダート 2 枚」「ダート → カイト 1 枚 + 半ダート 2 枚」になる。**P1 の置換と違って、子は必ず親の内側に生まれる**（辺の長さは 1 回で 1/φ に縮む）。はみ出しがないので重複をまとめる必要はないが、かわりに**半ダートは必ず親の長辺をまたいで生まれる**ので、ダートは 2 つの親にまたがってできる。

半タイルは頂点 3 つの並び `[p0, p1, p2]` で持ち、頂点ごとに役割を決める。どちらの型でも `p2–p0` が軸（タイルを半分に切った線）で、`p0–p1` と `p1–p2` がタイルの辺。

- 半カイト：p0 = 先端（72 度の頂点）、p1 = 横の頂点（72 度）、p2 = 広い頂点（144 度）
- 半ダート：p0 = へこんだ頂点（216 度）、p1 = とがり（36 度）、p2 = 72 度の頂点

分割は、この役割に沿って辺の上に 1 点ずつ取るだけで書ける。

- 半カイト：軸 `p0–p2` 上の 1/φ の点 w と、長辺 `p0–p1` 上の 1/φ² の点 z で切る → 半カイト `[p1, p2, w]`・`[p1, z, w]`（軸 `p1–w` を突き合わせて親の内側でカイト 1 枚になる）と、半ダート `[z, w, p0]`（親の長辺をまたぐ）
- 半ダート：長辺 `p1–p2` 上の 1/φ の点 v で切る → 半カイト `[p2, v, p0]`（軸が親の軸と重なるので、親の反対側の半分と組んでカイト 1 枚になる）と、半ダート `[v, p0, p1]`（親の長辺をまたぐ）

**種は「太陽」**（カイト 5 枚が先端を突き合わせた配置）。カイトの先端は 72 度なので 5 枚でちょうど一周し、外周は 1 辺が短辺の正十角形になる。分割しても領域は変わらないので、この十角形の内接円がそのまま「隙間なく埋まる範囲」になる。

### 準結晶として見る（P2 から取り出せる構造）

同じタイリングを「結晶」として描くために、タイルの塗り分け以外に 5 つの構造を取り出す。どれもタイリング自身から誤差なく計算できる。

**向き（orientation）。** タイルの軸（半分に切った線）の向きは、**必ず 36 度の倍数**になる。0〜9 の整数で持てるので、10 系統の結晶面として扱える。数値でも確かめられる：種の向きを 0 としたとき、軸の角度と 36 度の倍数とのずれは 2×10⁻¹⁵ ラジアン程度しか出ない。

**頂点の型（vertex type）。** 頂点に集まるタイルは 3〜5 枚で、内訳は 7 通りしかない。そのうち **カイト 5 枚（太陽）とダート 5 枚（星）だけが 5 回対称**なので、この 2 つは結晶格子の節点として区別できる。

**劈開線。** 頂点は、36 度ずつずれた 5 つの方向それぞれについて、**平行な直線の上にきれいに乗る**。間隔はほとんどが L と L/φ の 2 種類で、並びはフィボナッチ列になる。まれに L + L/φ の広い間隔が混じる（そこには頂点が乗らないので取れない）。

この線の間隔は短辺の 1/3 ほどで、劈開線としては密すぎる。間隔の並びは「L → LS、S → L」で伸びるフィボナッチ列なので、**短いほうの間隔を始める線を落とす**と、間隔が L+S と L の 2 種類に戻る——つまり φ 倍に引き伸ばした同じ形の列になる。これを 3 回繰り返すと（既定）、タイルと同じくらいの間隔になる。

これは **Ammann bar そのものではない**。Ammann bar はタイルの内側を通る補助線で、頂点は通らない。タイルの装飾として自前で決めると正しさを検算できないので、タイリング自身から取り出せるこの線族を使う。5 方向の平行線が φ 比の間隔で走るという性質は Ammann bar と同じ。

**回折像。** 頂点の点群 P の構造因子 S(k) = |Σ exp(-i k·p)|² を波数の平面で数えると、周期が無いのに **10 回対称の鋭いピーク**が立つ。これが「準結晶」という名前の由来でもある。有限の点群をそのまま変換すると切り口の段差がピークの裾を引くので、外へ行くほど重みを落とす窓関数をかける。

**多結晶。** 結晶核を複数置き、いちばん近い核の領域（ボロノイ領域）で分ける。核ごとに向きが違うので、境目では 2 つのタイリングが噛み合わない。**それぞれの粒が自分の側だけを描く**ようにタイルを境界で切ると、隙間も重なりも出ずに、岩石の研磨面のような直線の粒界ができる。

## 実装要件

- 正方形の SVG 画像として生成する（既定 480px 四方）
- ランダム性は seed 付き PRNG（mulberry32）で制御し、同じ seed からは同じ模様が再現される
- **色数 2〜6 のパターンを一度の実行で一括生成する**（`--color-count=4,5` のように色数を絞れる）
- **`--n` は範囲指定できる。** `--n=4,24` なら n = 4〜24 の全てを一度に生成し、出力先も一覧 HTML も 1 つにまとめる
- n を範囲で生成するとき、**seed に n を混ぜない。** 同じ色数なら n が変わっても帯の構成と配色がそろい、対称性の次数だけを見比べられる（基本領域の広さで要素の採否が変わるため、細部のアクセントは多少ずれる）
- **ロゼッタ版は描きたくない要素を `--exclude` で外せる**（`--exclude=spoke,dot`）。外した要素も組み立てまでは行って rng の消費列を変えないので、同じ seed の模様からその要素だけが消える
- **壁紙群版は 17 群を一度の実行で一括生成する**（`--group` で絞れる）
- 壁紙群版も同じ理由で、**seed に群を混ぜない。** 17 群で区画の構成と配色がそろい、対称性の違いだけを見比べられる
- **群をまたいで「基本領域」の面積をそろえる**（単位格子ではなく）。こうするとどの群でもモチーフが同じ大きさで現れ、並べ方の違いだけを見比べられる。単位格子の大きさは群ごとに変わる（p6m は p1 の 12 倍）
- **背景は白（`#FFFFFF`）で固定し、パレットの色は背景に使わない。** パレットの k 色はすべて模様の側で使う
- 色は「インデックスが小さいほど使用面積が大きい」順に並べる。壁紙群版は基本領域を細かくサンプルして、上に重ねた要素に隠れたぶんを除いた実際の使用面積を数える。最後にその順で色を並べ替えて、この順序を確定させる
- パレットに含まれる色は必ず 1 回以上使う。壁紙群版では「重ねた要素に完全に隠れて見えなくなった色」も取りこぼしとして扱い、点を置いて補う
- 既定パレットは 1 本のマスターリストの先頭 k 色。色数を増やしても色が入れ替わらないので、色数どうしを比較できる
- **ペンローズ版・カイト＆ダート版は 1 枚のタイリングを色数 2〜6 で一括生成する。** タイリング自体は置換・分割の規則で一意に決まるので、seed は模様ではなく「どこをどの向きで切り取るか」を決める
- この 2 版も同じ理由で、**seed に色数を混ぜない。** 色数を変えても切り取り方がそろい、配色の違いだけを見比べられる
- **準結晶版は切り取り位置を seed で振らない。** 結晶核を画面の中心に置くのがこの版の趣旨なので、seed が決めるのは全体の向きと、多結晶にしたときの核の位置だけ
- **準結晶版も seed に色数・コマ番号を混ぜない。** 同じ結晶を色数と成長のコマだけ変えて並べられる
- 生成した SVG は `.generated/{curved|angular}/{YYYYMMDD-THHMMSSZ}/d{n}-{k}colors.svg` に出力する。壁紙群版は `.generated/{wallpaper|wallpaper-round}/{YYYYMMDD-THHMMSSZ}/{群名}-{k}colors.svg`、ペンローズ版は `.generated/penrose/{YYYYMMDD-THHMMSSZ}/penrose-{k}colors.svg`、カイト＆ダート版は `.generated/kite-dart/{YYYYMMDD-THHMMSSZ}/kite-dart-{k}colors.svg`、準結晶版は `.generated/crystal/{YYYYMMDD-THHMMSSZ}/crystal-{k}colors.svg`（コマ送りのときは `-f01` のような連番が付く）
- 同じディレクトリに、生成物を並べて見るための `index.html` も出力する。n を範囲で生成したときは n ごとに、壁紙群版は群ごとに節を分ける（節の中に色数 2〜6 が並ぶので、同じ群で色数を増やしたときの見え方を比べられる）
- コンソールには生成した SVG ファイルへのパスと、生成にかかった時間を出力する（枚数が多いときはパスの代わりに件数を出す）

## ロゼッタ版が基本領域に描く要素

すべて `(level, θ)` の座標で位置を決める。level は「その角度における基本領域の外周までの距離」を 1 とした比率で、正 n 角形（または円）の輪郭に沿ってスケールされる。

| 要素 | 曲線版 | 直線版 |
| --- | --- | --- |
| band | 2 本のレベル曲線に挟まれた帯。面積を担う主要素。中心から外周までを 3〜8 本に分割する | 同じ。境界が鋸歯または階段状の折れ線になる |
| ribbon | レベル曲線をストロークした細い環 | 折れ線をストロークした細い環 |
| spoke | 半径方向にしなった曲線のストローク | まっすぐな放射線 |
| petal | 中心から外へ伸びる葉状の閉曲線 | 中心から外へ伸びる凧形 |
| shard | （なし） | 領域内のランダムな三角形 |
| blob | 領域内に収まるランダムな閉曲線 | 領域内に収まるランダムな多角形 |
| dot | 小さな円 | 小さな正方形・菱形 |
| center | 中心の円（不動点なのでコピーせず 1 個だけ描く） | 中心の正 n 角形 |

表の名前がそのまま `--exclude` で指定する名前になる（`--exclude=spoke,dot`）。shard は直線版にしかないので、曲線版で指定するとエラーになる。

輪郭の作り方だけが 2 つの版の違い。

- **曲線版**：θ を 4 点サンプリングして level をランダムに揺らし、Catmull-Rom 的な接線から 3 次ベジェに変換する。両端の接線だけは前述のとおり鏡映線に直交するよう固定する
- **直線版**：θ を 5〜10 点サンプリングし、level の揺らぎの符号を交互にして規則的な鋸歯にする。歯の数はすべての帯で共通なので、同心のジグザグとして読める。3 割の確率で「level を保ったまま θ を進めてから半径方向へ動く」階段状になり、城壁のような凹凸になる

## 壁紙群版が基本領域に描く要素

17 群を見比べるのが目的なので、どの群でも同じ組み立て方をする。

| 要素 | 内容 |
| --- | --- |
| sector（地の塗り分け） | 基本領域を中心から放射状に 3〜7 枚に切り分けて塗る。多角形を過不足なく覆うので、コピーすると平面が塗り残しなく埋まる |
| ring（入れ子の輪） | 5 割強の確率で、中心に基本領域の相似形を 1〜2 枚重ねる |
| mark（非対称な印） | 向きのわかる F 字を中心に置く。基本領域の内接円に収める。**この版は模様そのものを見せるのが目的なので既定では置かず、`--mark` を付けたときだけ描く** |
| dot（補いの点） | 上に重ねた要素に隠れて見えなくなった色があれば、その色の点を置いて補う |

区画の色は、ロゼッタ版と共通の帯のルール（幅の比を 0.6〜1.8 に収め、隣り合う区画を別の色にする）で決める。輪と印の色は共通の `accentColor`（下地と同色を避け、面積を小さく保ちたい色を優先する）で決める。

**印を置くなら非対称であることが肝心。** 対称な印だと、となりのコピーが回転なのか鏡映なのかすべり鏡映なのかが見分けられない。F 字は上下も左右も対称でないので、向きだけで対称操作が読み取れる。

ただし F 字は文字として読めてしまい、幾何模様の中では浮く。**この版は直線的な幾何模様そのものを生成するのが目的**なので、印は既定では置かず、群の対称性を観察したいときだけ `--mark` で足す。

## 壁紙群・丸み版が基本領域に描く要素

同じ目的（17 群の見比べ）を、丸い図形の組み合わせで描く版。構図・配色のルールは壁紙群版と共通で、形だけが違う。

| 要素 | 内容 |
| --- | --- |
| sector（地の塗り分け） | 壁紙群版と同じく放射状に 3〜7 枚に切り分けるが、切れ目を 2 次ベジェにする。**切れ目は 1 本ずつ作ってとなり合う区画で共有する**ので、曲げても基本領域を過不足なく覆う |
| corner（頂点の扇形） | 各頂点に、その内角ぶんの扇形を置く。基本領域のコピーは頂点のまわりで 2π を埋めるので、**コピーが集まると扇形が合わさって完全な円になる**。4 割強の確率で内側にもう 1 段重ね、同心の輪に見せる |
| edge（辺の中点の半円） | 5 割の確率で、各辺の中点に内側を向く半円を置く。辺を共有するとなりのコピーの半円と合わさって円になる |
| ring（同心円） | 5 割強の確率で、中心に円を 1〜2 枚重ねる |
| mark（非対称な印） | 巴形（内へ巻き込む螺旋を、頭を太く尾を細く肉付けしたもの）を中心に置く。**巻く向きが固定なので鏡像とは重ならない**。この版は群の見比べが目的なので既定で置き、`--no-mark` で外せる |
| dot（補いの点） | 壁紙群版と同じ |

**膨らみの向きは 1 つの模様の中でそろえる。** 区画が風車のように読めて、鏡像との違いが際立つ。

丸い図形も基本領域からはみ出せない（クリップするとコピーの継ぎ目にアンチエイリアスの筋が出る）ので、半径はすべて領域の内側に収まる値で頭打ちにする。切れ目のベジェは制御点を領域の内側に収めれば、凸性から曲線全体も内側に収まる。

**扇形の半径は頂点ごとに変えず、いちばん厳しい頂点に合わせて 1 つに決める。** 頂点のまわりに集まるのが基本領域のどの頂点かは群によって違うので、半径をそろえておかないと合わさった円の縁が欠ける。大きさの基準には内接円ではなく √（基本領域の面積）を使う。基本領域の面積は群でそろえてあるので、こうすると円の大きさも群でそろう（基本領域に短い辺がある p2・pg だけは、辺の長さで頭打ちになって小さくなる）。

### 対称性の要素（`--guide`）

比較の助けとして、模様の上に対称性の要素を重ねられる。

| 表示 | 意味 |
| --- | --- |
| 実線の平行四辺形 | 単位格子 |
| 細かい破線の多角形 | 基本領域（群の変換ぶんを敷き詰めたもの） |
| 太い実線 | 鏡 |
| 破線 | すべり鏡 |
| レンズ・三角・四角・六角 | 回転中心（2・3・4・6 回） |

回転中心は変換の不動点 `x = (I − A)⁻¹·c` として、鏡とすべり鏡は鏡映変換の並進を鏡に平行な成分と垂直な成分に分けて求める。**平行な成分が 0 なら純粋な鏡、残れば すべり鏡**。同じ軸に両方が乗るときは鏡として扱う。

## ペンローズ版が描く要素

タイリングが置換規則で一意に決まるので、模様の側にランダムな要素はない。**違いは「どこをどの向きで切り取るか」と「タイルをどう色分けするか」で作る。**

| 要素 | 内容 |
| --- | --- |
| tile | 4 種のタイルそのもの。輪郭を塗りつぶす |
| outline | `--outline` のとき、タイルの輪郭を背景色の細線で描く。タイルの切れ目が見えるので、タイリングの構造そのものを見たいときに使う |

色分けは、タイルの種類と「置換規則のどの位置から生まれたか」で決める。色数を増やすと分け方が細かくなるだけで、前の分け方は崩れない（既定パレットが色数を増やしても色を入れ替えないのと同じ考え方）。

| 色数 | 分け方 |
| --- | --- |
| 2 | 五角形 / 星・舟・菱形 |
| 3 | 五角形 / 星・舟 / 菱形 |
| 4 | 五角形 / 星 / 舟 / 菱形 |
| 5 | 五角形（五角形から生まれたもの）/ 五角形（星・舟・菱形の中に生まれたもの）/ 星 / 舟 / 菱形 |
| 6 | 五角形（中心）/ 五角形（頂点側）/ 五角形（隙間の中）/ 星 / 舟 / 菱形 |

色番号は最後に、**画面内に見えているぶんの面積**の大きい順へ振り直す。面積は五角形（頂点側）がおよそ 6 割を占め、星・舟・菱形はそれぞれ 1 割に満たない。

切り取り位置は中心からの距離と向きで決める。距離は面積が一様になるようにとる（半径に √ をかける）。回転は五角形の対称性から 72 度ぶん振れば見え方を尽くせる。

## カイト＆ダート版が描く要素

こちらもタイリングに乱数の余地はないので、**違いは「どこをどの向きで切り取るか」と「タイルをどう色分けするか」で作る。**要素はペンローズ版と同じ `tile` と `outline` の 2 つで、切り取り方の決め方も共通。

色分けは、タイルの種類と「どのタイルから生まれたか」で決める。**カイトは親が 1 枚に定まる**ので親（と、その親）の種類で分けられる。**ダートは 2 つの親にまたがる**ので、両側の親の種類の組で分ける。

| 色数 | 分け方 |
| --- | --- |
| 2 | カイト / ダート |
| 3 | カイト（親がカイト）/ カイト（親がダート）/ ダート |
| 4 | 上の 3 つ + ダートを「両側の親がカイト」と「それ以外」に分ける |
| 5 | ダートを「両側カイト」「カイトとダート」「両側ダート」の 3 つに分ける |
| 6 | カイト（親がカイト）を、祖父母がカイトかダートかで 2 つに分ける |

色数を増やすと分け方が細かくなるだけで、前の分け方は崩れない（ペンローズ版と同じ考え方）。色番号は最後に、**画面内に見えているぶんの面積**の大きい順へ振り直す。面積の内訳はおおよそ、カイト（親カイト・祖父母カイト）4 割強、カイト（親ダート）1 割 7 分、カイト（親カイト・祖父母ダート）1 割 3 分、ダートは 3 種を合わせて 3 割弱（両側カイト 1 割 3 分・カイトとダート 8 分・両側ダート 7 分）。枚数の比はカイト : ダート ＝ φ : 1。

## 準結晶版が描く要素

同じタイリングを「鉱物の標本」として見せるために、6 つの層を重ねる。`--layers` で選び、既定は `diffraction,tile,cleave,network`（結晶核が複数なら `grain` も足す）。

| 層 | 内容 |
| --- | --- |
| tile | タイルの面。向きから結晶面（ファセット）の法線を作り、斜めからの光で陰影をつける。光の当たった稜線は背景色で抜き、背いた稜線はインクで沈める |
| edge | タイルの輪郭。タイリングの構造そのものを見たいときに足す |
| cleave | 劈開線。頂点が乗る平行線族を φ のべきで粗くして引く。頂点の多い線は太く濃く（濃さは `--cleave-opacity` でまとめて落とせる） |
| network | 頂点と辺のネットワーク。節点は集まるタイルの枚数で大きさを変え、5 回対称の頂点（太陽・星）だけ十角形にする |
| diffraction | 頂点の点群の回折像。ピークの強さで円の大きさと濃さを決める |
| grain | 粒界。ボロノイ領域の境目を、背景色の溝＋細い線の割れ目として描く |

**結晶核は画面の中心に置く**（多結晶なら各核の位置）。種の太陽は原点にあり、分割は合同変換と可換なので、**タイリング全体が中心のまわりで正確に D5 対称**になる。数値でも確かめられる：中心付近のタイルを 72 度回すと、種類も位置も 1 枚残らず元のタイルに重なる（鏡映も同じ）。中心から離れるほど非周期に見えるという「マクロでは対称、ローカルでは非周期」の見え方が、そのまま絵になる。

色分けは 3 通りから選ぶ（`--color-by`）。

| 方式 | 分け方 | 見え方 |
| --- | --- | --- |
| orientation（既定） | 軸の向き（10 系統）を色数ぶんに等分する | 結晶面の系統ごとに色が変わる。72 度回すと向きが 2 つずれるので、5 回対称は色の風車として現れる |
| class | どのタイルから生まれたか（カイト＆ダート版と同じ表を使う） | 回転で変わらない分け方なので、中心の 5 回対称がそのまま見える |
| zone | 核からの距離。境目の半径を φ で縮めていく | 鉱石の成長痕のような同心の輪になる |

どの方式でも、色番号は最後に**見えている面積の大きい順**へ振り直す（他の版と同じ）。

**成長（`--growth`）** は結晶化が届いた半径を決める。境目にはタイル数枚ぶんの帯があり、外から順に 何も無し → 輪郭だけ → 半透明の面 → 結晶面 と変わる。帯の位置はタイルごとに揺らすので、縁は円ではなくぎざぎざになる。`--frames` で growth を振れば、中心から析出していくコマ送りが 1 回の実行で出せる。

## 設計上の判断

- **クリップしない**：基本領域でクリップすると、隣り合うコピーの境界にアンチエイリアスの継ぎ目（2n 本の放射状の線）が出る。代わりに各要素が基本領域の内側に収まるよう生成時に制約する。ストロークは半分だけ鏡映線をまたぐが、鏡像と重なるので問題にならない
- **丸みは「輪郭を曲げる」のではなく「切れ目を曲げる・輪郭に噛み合う扇形を置く」で出す**：基本領域の輪郭そのものを曲げると平面を敷き詰められなくなる。地は切れ目だけを曲げ（となり合う区画で共有するので覆いは崩れない）、丸い形は頂点・辺の中点に置いてとなりのコピーと噛み合わせる。こうすると領域の内側に収めたまま、模様の側では基本領域をまたいだ完全な円が現れる
- **塗りにヘアライン**：帯の塗りには同色の `stroke-width: 0.7` を足し、コピー間の継ぎ目を消す
- **アクセントのレベル上限**：最外周の帯が最も内側へ凹むレベルを上限にする。これを超えると、線や点が模様の輪郭の外へ飛び出して見える
- **階段状の最後の段差は潰す**：θ=α の鏡映線にちょうど重なり、帯が幅ゼロの針になる。塗りには出ないのにヘアラインだけが線として見えてしまう
- **`--exclude` は乱数を消費したまま捨てる**：要素を作らずに飛ばすと rng の消費列がずれ、`--exclude=dot` を付けただけで帯の分割も配色も別物になる。組み立ててから捨てれば「同じ絵からその要素だけが消えた絵」になり、見比べに使える。ただし色を使い切るための補いは除外できない（不変条件を優先する）ので、消した要素が唯一の担い手だった色は、代わりに補いの環として出てくる
- **`<use>` によるコピー**：基本領域の模様を `<defs>` 内の `<g>` として 1 度だけ定義し、2n 個の `<use>` で変換配置する。壁紙群版は 3 段構えで、基本領域 → 群の変換で単位格子 1 枚 → 平行移動で敷き詰め、と `<use>` を重ねる
- **単位格子はキャンバスの中心に合わせて敷く**：キャンバスの中心に単位格子の中心を置き、外側は 2 枚ぶん多めに敷いて viewport で切る。基本領域は単位格子の外へはみ出しうるので、1 枚ぶんの余裕では縁が欠けることがある
- **面積の順序は最後に確定させる**：基本領域をサンプルすれば実際に見えている面積を数えられるので、配色の重み付けに任せず、最後に使用面積の大きい順へ色を並べ替える。色の入れ替えなので、隣り合う区画やアクセントと下地が同色にならない性質は保たれる
- **隠れて消えた色も取りこぼしとして扱う**：入れ子の輪や印が下の要素を覆いきってしまうことがある。要素を数えるだけでは気づけないので、上から見えている面積で判定する
- **ペンローズ版の敷き詰めは数値で検算する**：点をサンプルして、各点を覆うタイルがちょうど 1 枚かを数える。はみ出したタイルと重複まとめで組み立てているので、規則の取り違えは必ず隙間か重なりとして出る
- **ペンローズ版は描画範囲から遠いタイルを各段で捨てる**：置換のたびにタイルは約 φ²（2.6 倍）に増える。置換で生まれるタイルが親の位置から届く距離には上限があるので、その余裕をとって外側を捨てれば、見えるタイル数に比例した枚数で済む（480px・五角形 8 枚ぶんで 400 枚程度）
- **ペンローズ版の向きは 36 度を 1 とする整数で持つ**：タイルの向きはすべて 36 度の倍数になる。整数にしておけば「五角形の向きは 2 種類で、辺で接する五角形どうしは必ず違う」といった判定が誤差なくでき、菱形の矢印の向きも一意に決められる
- **カイト＆ダート版は半タイルで分割し、最後に突き合わせて戻す**：分割規則が書けるのは半タイル（ロビンソン三角形）の上だけ。描くときは軸の辺をキーにして 2 枚ずつ組にし、カイト・ダートに戻す。半分のまま描くと、`--outline` のときに本来ないはずの線が入る
- **カイト＆ダート版の枝刈りはタイル 2 枚ぶんの余裕を残す**：子は親の内側にしか生まれないので、描画範囲から遠い親は各段で捨ててよい。ただし相方の半タイルまで捨てると突き合わせられないので、余裕を持たせる。相方が見つからない半タイルは半分のまま描くが、画面の縁から短辺 1 個ぶん以上は外側にしか出ない
- **カイト＆ダート版の色分けはダートを「両側の親」で分ける**：半ダートは必ず親の長辺をまたいで生まれるので、ダートには親が 2 枚ある。片方だけを見ると、同じ形のダートが切り取り位置によって別の色になってしまう
- **準結晶版の劈開線はタイルに描かず、タイリングから取り出す**：Ammann bar をタイルの装飾として自前で決めると、隣り合うタイルで線がつながるかを検算できない。頂点が乗る平行線族なら、頂点を法線方向へ射影して数えるだけで求まり、間隔が φ : 1 の 2 種類になることまで数値で確かめられる
- **準結晶版の劈開線はフィボナッチ列の逆変換で粗くする**：頂点が乗る線は短辺の 1/3 ほどの間隔で並ぶので、そのままでは密すぎる。「短いほうの間隔を始める線を落とす」と間隔が φ 倍に伸びた同じ形の列になるので、必要な回数だけ繰り返す。線を間引く量を割合で決めると、間隔の並びが崩れてタイリングとの対応が切れる
- **準結晶版の回折像はいちばん上に薄く重ねる**：背面に置くとタイルの面に隠れて 1 つも見えない。逆空間の像なので実空間のタイルとは重ならなくてよく、上に重ねても構造を隠さない
- **回折のピークは円の中だけ・リング単位で採る**：波数は正方形の範囲で数えるが、四隅まで採ると円からはみ出したぶんでリングが欠け、10 回対称が崩れて見える。強さの順に上から N 個で切っても同じことが起きるので、同じ |k| のピークはまとめて採る
- **多結晶は粒の境界でタイルを切る**：重心で「どちらの粒か」を決めて捨てると、境目に隙間が空く（となりの粒は別のタイリングなので、その穴を埋められない）。両方の粒がそれぞれ自分の側だけを描けば、隙間も重なりも出ない。ただし向きや親子の情報は切る前の形から取る（切った形からは軸が求まらない）
- **準結晶版は面と線を同時に描くとき、頂点ネットワークを控えめにする**：線が主役の絵（面を描かない指定）と同じ濃さのまま面の上に重ねると、線だけが目立って結晶面が読めなくなる

## 使い方

オプションはロゼッタの 2 つのスクリプトで共通。

```bash
node src/generate.js                       # 曲線版・色数 2〜6 を一括生成
node src/generate-angular.js               # 直線版・色数 2〜6 を一括生成

node src/generate.js --n=9                 # 正九角形の対称性
node src/generate.js --n=4,24              # n = 4〜24 を範囲で一括生成（--n=4-24 も可）
node src/generate.js --seed=12345          # 再現可能な生成
node src/generate.js --count=3             # 色数ごとに 3 種類ずつ
node src/generate.js --shape=circle        # 正 n 角形ではなく円形に収める
node src/generate.js --size=800            # 出力サイズ
node src/generate.js --color-count=4,5     # 生成する色数を絞る（既定は 2〜6 すべて）
node src/generate.js --colors='#fff,#123'  # パレットを指定（その色数のみ生成）
node src/generate.js --exclude=spoke,dot   # 描かない要素を指定する
node src/generate.js --help                # ヘルプ
```

壁紙群版は `--n` と `--shape` のかわりに、群と敷き詰めの細かさを指定する。

```bash
node src/generate-wallpaper.js                    # 17 群 × 色数 2〜6 を一括生成
node src/generate-wallpaper.js --group=p6m,p4g    # 群を絞る
node src/generate-wallpaper.js --repeat=8         # キャンバスの横幅あたりの基本領域の枚数
node src/generate-wallpaper.js --guide            # すべての出力に対称性の要素を重ねる
node src/generate-wallpaper.js --mark             # 非対称な印を置く（既定は置かない）
node src/generate-wallpaper.js --help             # ヘルプ

node src/generate-wallpaper-round.js              # 丸み版（オプションは壁紙群版と共通）
node src/generate-wallpaper-round.js --no-mark    # 丸み版は既定で印あり。外すときはこちら
```

ペンローズ版は群を持たないので、指定するのはタイルの細かさと輪郭の有無だけ。

```bash
node src/generate-penrose.js                      # 色数 2〜6 を一括生成
node src/generate-penrose.js --repeat=16          # キャンバスの横幅あたりの五角形の枚数（既定 8）
node src/generate-penrose.js --outline            # タイルの輪郭を背景色の細線で描く
node src/generate-penrose.js --count=3            # 切り取り方を 3 通り
node src/generate-penrose.js --help               # ヘルプ
```

カイト＆ダート版のオプションはペンローズ版と共通（`--repeat` の数えかたが五角形からカイトに変わる）。

```bash
node src/generate-kite-dart.js                    # 色数 2〜6 を一括生成
node src/generate-kite-dart.js --repeat=16        # キャンバスの横幅あたりのカイトの枚数（既定 8）
node src/generate-kite-dart.js --outline          # タイルの輪郭を背景色の細線で描く
node src/generate-kite-dart.js --count=3          # 切り取り方を 3 通り
node src/generate-kite-dart.js --help             # ヘルプ
```

準結晶版はカイト＆ダート版と同じタイリングを使うので、`--repeat` の意味も共通。そのうえで、重ねる層と結晶の見せ方を指定する。

```bash
node src/generate-crystal.js                          # 色数 2〜6 を一括生成（既定の重ね方）
node src/generate-crystal.js --layers=tile,cleave      # 面と劈開線だけ（頂点と回折を外す）
node src/generate-crystal.js --layers=cleave,network   # 面を描かず、結晶格子だけを残す
node src/generate-crystal.js --layers=tile,edge --flat # 陰影なしで、タイリングの構造を見る
node src/generate-crystal.js --color-by=zone           # 成長痕のような同心の色分け
node src/generate-crystal.js --color-by=class          # 中心の 5 回対称が見える色分け
node src/generate-crystal.js --growth=0.6              # 途中まで析出した結晶
node src/generate-crystal.js --frames=8                # 成長のコマ送りを 8 枚
node src/generate-crystal.js --seeds=4                 # 多結晶（粒界が出る）
node src/generate-crystal.js --cleave=4 --light=40     # 劈開線をより粗く、光を別の向きから
node src/generate-crystal.js --layers=cleave --cleave-opacity=0.5 # 劈開線だけを淡く引く
node src/generate-crystal.js --help                    # ヘルプ
```

| オプション | 既定 | 内容 |
| --- | --- | --- |
| `--repeat` | 12 | キャンバスの横幅あたりのカイトの枚数（2〜40） |
| `--layers` | `diffraction,tile,cleave,network` | 描く層。核が複数なら `grain` も既定に入る |
| `--color-by` | `orientation` | `orientation` / `class` / `zone` |
| `--cleave` | 3 | 劈開線の粗さ。1 増やすごとに間隔が φ 倍（0〜5） |
| `--cleave-opacity` | 1 | 劈開線の濃さの倍率（0〜1）。太さは変えない |
| `--growth` | 1 | 結晶化の進み具合（0〜1） |
| `--frames` | 1 | growth を 0 から振って出すコマ数（1〜24） |
| `--seeds` | 1 | 結晶核の数（1〜8） |
| `--light` | 135 | 光源の方位（度） |
| `--flat` | なし | ファセットの陰影と稜線を切る |

`--seed` `--count` `--size` `--color-count` `--colors` `--out` は 7 つのスクリプトで共通。`--colors` はパレットで色数まで決まるので、`--color-count` とは同時に指定できない。
