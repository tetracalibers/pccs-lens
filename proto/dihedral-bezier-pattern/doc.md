# 二面体群ベジェパターン生成プロトタイプ

## 概要

正 n 角形の合同変換群（二面体群 D_n）の対称性をもつ模様を、ランダムなベジェ曲線から生成するアルゴリズムのプロトタイプ。

基本領域（fundamental domain）にだけランダムな模様を描き、群の 2n 個の変換すべてでコピーすることで、全体として D_n の対称性をもつロゼッタ模様（メダリオン）を作る。

## 技術スタック

- 依存パッケージなしの素の JavaScript（ESM）で実装する
- `node src/generate.js` で実行することで、SVG ファイルが生成されるようにする
- SVG は文字列として直接組み立てる

## 数学的な下敷き

### 二面体群 D_n

正 n 角形を自分自身に重ねる合同変換は 2n 個ある。

- 回転 `r^k`（k = 0..n-1）：中心まわりに 360k/n 度
- 鏡映 `r^k · m`（k = 0..n-1）：鏡映してから回転

### 基本領域

正 n 角形の中心 O・辺の中点 M・頂点 V が作る直角三角形 △OMV が基本領域になる。2n 個のコピーで正 n 角形をちょうど覆う。

α = π/n として、内接円半径（アポテム）を a とすると

- O = (0, 0)
- M = (a, 0) … 角度 θ = 0 の方向
- V = (a, a·tan α) … 角度 θ = α の方向

θ = 0 と θ = α の 2 本の半直線が鏡映線であり、この 2 枚の鏡が D_n 全体を生成する。

### 鏡映線での滑らかな接続

基本領域を θ=0 から θ=α まで横断する曲線の両端で、**接線を鏡映線に直交させる**と、その曲線と鏡像が端点で滑らかにつながる。結果として 2n 個のコピー全体が 1 本の閉じた波打つ環になる。

本プロトタイプの帯（band）とリボン（ribbon）はこの性質を使っている。

- θ=0 側の端点の接線方向：`(0, 1)`
- θ=α 側の端点の接線方向：`(-sin α, cos α)`

## 実装要件

- 正方形の SVG 画像として生成する（既定 480px 四方）
- ランダム性は seed 付き PRNG（mulberry32）で制御し、同じ seed からは同じ模様が再現される
- **色数 2〜6 のパターンを一度の実行で一括生成する**
- 色は「インデックスが小さいほど使用面積が大きい」順に並べる（`colors[0]` が背景）
- パレットに含まれる色は必ず 1 回以上使う
- 生成した SVG は `.generated/{YYYYMMDD-THHMMSSZ}/d{n}-{k}colors.svg` に出力する
- 同じディレクトリに、生成物を並べて見るための `index.html` も出力する
- コンソールには生成した SVG ファイルへのパスと、生成にかかった時間を出力する

## 基本領域に描く要素

すべて `(level, θ)` の座標で位置を決める。level は「その角度における基本領域の外周までの距離」を 1 とした比率で、正 n 角形の輪郭に沿ってスケールされる。

| 要素 | 内容 |
| --- | --- |
| band | 2 本のレベル曲線に挟まれた帯。面積を担う主要素。中心から外周までを 3〜8 本の帯に分割する |
| ribbon | レベル曲線をストロークしただけの細い環 |
| spoke | 半径方向にしなった曲線のストローク |
| petal | 中心から外側へ伸びる葉状の閉曲線 |
| blob | 基本領域の内側に収まるランダムな閉曲線 |
| dot | 小さな円 |
| center | 中心の円（不動点なのでコピーせず 1 個だけ描く） |

レベル曲線は、θ を 4 点サンプリングして level をランダムに揺らし、Catmull-Rom 的な接線から 3 次ベジェに変換して作る。両端の接線だけは前述のとおり鏡映線に直交するよう固定する。

## 設計上の判断

- **クリップしない**：基本領域でクリップすると、隣り合うコピーの境界にアンチエイリアスの継ぎ目（2n 本の放射状の線）が出る。代わりに各要素が基本領域の内側に収まるよう生成時に制約する。ストロークは半分だけ鏡映線をまたぐが、鏡像と滑らかに重なるので問題にならない
- **塗りにヘアライン**：帯の塗りには同色の `stroke-width: 0.7` を足し、コピー間の継ぎ目を消す
- **`<use>` によるコピー**：基本領域の模様を `<defs>` 内の `<g>` として 1 度だけ定義し、2n 個の `<use>` で変換配置する

## 使い方

```bash
node src/generate.js                       # 色数 2〜6 を一括生成
node src/generate.js --n=9                 # 正九角形の対称性
node src/generate.js --seed=12345          # 再現可能な生成
node src/generate.js --count=3             # 色数ごとに 3 種類ずつ
node src/generate.js --shape=circle        # 正 n 角形ではなく円形に収める
node src/generate.js --size=800            # 出力サイズ
node src/generate.js --colors='#fff,#123'  # パレットを指定（その色数のみ生成）
```
