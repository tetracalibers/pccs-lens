# thinking-flow（根拠インデックス）

`writing-guides/thinking-flow.md` の各ルールを支持する記事の索引。**analyzer 専用。`author-style-writer` は読まない。**

## 形式

1記事1ファイル。ファイルパスがそのまま記事 slug に対応する（`cg/basics/anti-aliasing.md` ＝ `/cg/basics/anti-aliasing`）。

```markdown
分析時点: `d8bd3563`
記事タイプ: 概念解説

- TF-020（冒頭で直前記事の未着手部分を呼び戻し、今まさに生じる問いを立てる）
- TF-038（α 値や混合比を言葉で読み下す）
  ※ TF-006：例外が少ない題材のため、限定条件の後置構造が目立たない
```

- **`- <ルールID>（該当箇所）` の行だけが支持である。** 括弧内は本文中の該当箇所を短く。
- `※` 行は反例・除外の注記で、**支持には数えない**。「反例」は判断が働かなかった箇所、「除外」はテーマ由来・記事タイプ由来などで根拠に数えない箇所。直前の支持行に紐づけて置く。
- ルールはIDで参照する。ルール名を書かないのは、短縮形で書かれると機械照合が壊れるため（ID は改名しても変わらず、廃止しても欠番として残る）。
- `分析時点` は、分析した本文のコミット（`app/src/routes/<slug>/+page.svx` を最後に変更したコミット）の短縮SHA。**記録した SHA が現在の最終更新コミットと違えば、その記事は分析後に改稿されている。** 再分析の対象を洗い出すときはこの比較で判定する。同じ記事なら4観点で同じ値になる。
- `記事タイプ` は分析時に分類した種別。移行で作られたファイルは `未記録` のままで、再分析した時点で埋まる。

## 支持記事数の数え方

確度は導出値である。ルールを支持する記事数は次で求める。

```sh
node scripts/style-evidence-tally.mjs --aspect thinking-flow --full
grep -rlE '^- TF-020' writing-guides/evidence/thinking-flow/ | wc -l   # 1ルールだけ見るとき
```

`※` 行を数えないよう、grep では行頭の `- ` を含めて照合する。

記事を再分析するときは、**当該記事のファイルだけ**を書き直す（他の記事のファイルには触らない）。

## 根拠の性質に関する注意

`thinking-flow.md` は完成記事の本文からの推測を扱うため、根拠は「本文にそう書かれている」ことしか示せない。判断の意図（記憶のためか理解のためか、証拠として使う意図があるか等）は本文からは切り分けられないため、確度の判定では次を区別する。

- **直接確認できる事実**：語順・リストと見出しの対応・強調対象の選択など、本文の形から機械的に確認できるもの。
- **強い推測**：複数記事・複数の記事タイプで同型が反復し、著者の選択とみなせるもの。
- **限定的な推測**：記述量の偏りなど、意図の反映か内容量の反映かを本文から切り分けられないもの。

また、次の切り分けを確度の上限に反映する。

- 対比・具体例の先出し・抽象→具体の翻訳など、**一般的な説明技法と重なる判断は確度を条件付き以下に抑える**。著者固有性は徹底度や具体的な言い回しに置く。
- **テーマ主導の面がある判断**（PCCS制約への言及、通史での因果叙述、比較記事での対比など）は、テーマ必然を超える部分だけを根拠に数える。
- 共有コンポーネント（`:::Action`・`:::Note` 等）や記法規約に依存する観察は、機械的運用と著者判断を切り分けられないため確度を抑える。
- 根拠が単一シリーズ・近接時期に閉じる傾向は、確度を **条件付きの傾向以下**に抑える。
- 根拠が1記事1箇所に閉じる観察は、主要ルールにせず `pending/thinking-flow.md` へ分離する。

## 移行時の注記

このインデックスは既存ガイドの根拠・確度欄から機械的でない抽出を行って作成したもので、**網羅的な記事リストではない**。記事を特定せず集約されていた根拠は、本文で個別に名指しされた記事にのみ登録している。各記事を再分析した時点で、その記事のファイルを正しい内容へ置き換える。

このため、**支持記事数が少ないことは根拠が弱いことを意味しない**（登録漏れのことがある）。確度の降格を機械化するときは、そのラウンドで書き直した記事に関係するルールだけを対象にする（`style-evidence-tally.mjs --round`）。
