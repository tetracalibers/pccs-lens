# stylistic-quirks（根拠インデックス）

`writing-guides/stylistic-quirks.md` の各ルールを支持する記事の索引。**analyzer 専用。`author-style-writer` は読まない。**

## 形式

1記事1ファイル。ファイルパスがそのまま記事 slug に対応する（`cg/basics/anti-aliasing.md` ＝ `/cg/basics/anti-aliasing`）。

```markdown
分析時点: `d8bd3563`
記事タイプ: 概念解説

- SQ-032（「このように、高い解像度で細かく色を求めてから平均することで…」）
- SQ-047（「透明度（$$\alpha$$値）」）
  ※ SQ-049：漢字「例えば」が混在し「たとえば」は統一されない
```

- **`- <ルールID>（該当箇所）` の行だけが支持である。** 括弧内は本文中の該当箇所を短く。
- `※` 行は反例・除外の注記で、**支持には数えない**。「反例」はその癖が働かなかった箇所、「除外」は記事タイプ由来・テーマ由来などで根拠に数えない箇所。直前の支持行に紐づけて置く。
- ルールはIDで参照する。**ルール名を書かないのは、この観点でとくに短縮形が使われて機械照合が壊れていたため**（`ヘッジ文末` ／ `要約・一般化の接続` ／ `本質を言い切る結び` など、本体の見出しは補足句を伴う長い名前になっている）。ID は改名しても変わらず、廃止しても欠番として残る。
- `分析時点` は、分析した本文のコミット（`app/src/routes/<slug>/+page.svx` を最後に変更したコミット）の短縮SHA。**記録した SHA が現在の最終更新コミットと違えば、その記事は分析後に改稿されている。** 再分析の対象を洗い出すときはこの比較で判定する。同じ記事なら4観点で同じ値になる。
- `記事タイプ` は分析時に分類した種別。移行で作られたファイルは `未記録` のままで、再分析した時点で埋まる。

## 支持記事数の数え方

確度は導出値である。ルールを支持する記事数は次で求める。

```sh
node scripts/style-evidence-tally.mjs --aspect stylistic-quirks --full
grep -rlE '^- SQ-032' writing-guides/evidence/stylistic-quirks/ | wc -l   # 1ルールだけ見るとき
```

`※` 行を数えないよう、grep では行頭の `- ` を含めて照合する。

記事を再分析するときは、**当該記事のファイルだけ**を書き直す（他の記事のファイルには触らない）。

## 根拠の性質に関する注意

`stylistic-quirks.md` は語形・文末・接続・表記といった表層の選択を扱うため、根拠は「その語形が出現する／出現しない」という形で確認できる。一方、多くの語形は日本語の技術文書一般に共通するため、確度の判定では次を区別する。

- **著者固有性のある選択**：語そのものではなく、何に当てるか・何に当てないかという配分（例：ヘッジを主観・一般則に当て定義・手順には当てない）。
- **一般的技法との重なり**：です・ます調、括弧注記、「〜と呼ばれる」、「ことがわかります」など、それ自体は汎用の語形。確度は配分の一貫性で判定し、語形の出現数では上げない。
- **記法・共有コンポーネント由来**：`:Anki`・`:::Action`・TermCard など、サイト共通の仕組みに依存する観察は、機械的運用と著者判断を切り分けられないため確度を抑える。
- **テーマ主導**：題材が語彙を誘発する場合（変換の保存性テーマでの「そのまま」、対比記事での対比接続など）は、テーマ必然を超える部分だけを根拠に数える。
- 根拠が単一シリーズ・近接時期に閉じる傾向は、確度を **条件付きの傾向以下**に抑える。
- 根拠が1記事1箇所に閉じる観察は、主要ルールにせず `pending/stylistic-quirks.md` へ分離する。

## 移行時の注記

このインデックスは既存ガイドの根拠欄から機械的でない抽出を行って作成したもので、**網羅的な記事リストではない**。「全記事」「色の理論9本」のように記事を特定せず集約されていた根拠は、本文で個別に名指しされた記事にのみ登録している。各記事を再分析した時点で、その記事のファイルを正しい内容へ置き換える。

このため、**支持記事数が少ないことは根拠が弱いことを意味しない**（登録漏れのことがある）。確度の降格を機械化するときは、そのラウンドで書き直した記事に関係するルールだけを対象にする（`style-evidence-tally.mjs --round`）。
