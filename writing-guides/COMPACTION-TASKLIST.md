# スタイルガイド コンパクト化タスクリスト

`spec/writing-guides-compaction.md` に基づく移行作業の進捗記録。

- 仕様の全文は `spec/writing-guides-compaction.md`（7,665字）。**各セッションの冒頭で必ず読む。**
- チェック済み `[x]` … その節の移行（手順1〜3）が完了し、コミット済み
- 未チェック `[ ]` … 未着手
- 移行は**節（`##`）単位**で行う。1セッションで1フェーズを目安とする。
- 作業対象が大きいため、4ファイル計 303,574字を1セッションでは処理できない。フェーズ単位で分割する。

## 各節で行うこと（手順1〜3）

1. **抽出と昇格を1パスで行う**
   - 各ルールの `根拠` `確度` を読み、記事名を `evidence/<観点>.md` へ登録する
   - 根拠・確度の散文に埋もれている**実行可能な制約**を、`ルール` / `適用しない状況` / 新規項目へ昇格させる
   - 昇格させた制約は**差分として著者に提示し、確認を得る**（受け入れ条件5）
2. **根拠・確度の散文を削除**する。`確度` はラベル3語のみに置換する
3. **反例・関連ルールを圧縮**する
   - 一般化できる反例は「適用しない状況」へ吸収し、記事固有の反例は削除する
   - `関連ルール` は裸の参照のみにする（`→ thinking-flow.md「◯◯」`）
   - `pending/` への参照は削除する

**注意：根拠欄をスクリプトで機械的に切り落とさない。** ルール欄・適用条件欄に無い制約が埋もれているため、1ルールずつ読んで判断する。
