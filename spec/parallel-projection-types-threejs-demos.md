## 案3+4：軸測投影の3種類（実装済み）

| | |
| --- | --- |
| ディレクトリ | `app/src/lib/demo/threejs/transformation/parallel-projection-types/axonometric/` |
| 公開関数 | `createAxonometricScene` |
| 挿入位置 | 「軸測投影」節、等測投影の説明と `:::Note` の直後 |
| コミット | `21005a6f` |

左右2面構成。左「立方体と投影面」に立方体・3本の座標軸・投影面・投射線・投影面に写った像を斜めから見た向きで置き、右「投影面に写った像」にその像を正面から見たものと、縮まなかったときの軸の先を示す円を描く。

### 実装の要点

**投影面を `xy` 平面に固定し、形状の側を回している。** 投影面を傾けるのと相対的な関係は同じで、投影面が画面と平行なままになるぶん像を正面から読み取れる。形状に掛ける回転は `R = Rx(仰角) · Ry(-方位角)` で、これは投影面に垂直な向きを `z` 軸に重ねる回転にあたる。この形にすると**直投影が「`z` を落とすだけ」**になり、掲載コードが短くなる。

- 縮み率 = 長さ1の軸の像の長さ（`Math.hypot(回転後のx, 回転後のy)`）
- 種類の判定は**表示に出す2桁に丸めた値**で行い、数値と種類が食い違わないようにしている

### プリセット

スライダーの刻みでは合わせられない角度なので、選んで飛べるようにしている。値は2桁に丸めてあり、丸めても判定が変わらないことは計算で確認済み。

| プリセット | 方位角 | 仰角 | 縮み率 | 軸のなす角 |
| --- | --- | --- | --- | --- |
| 等測 | `45` | `35.26` | `0.82 / 0.82 / 0.82` | `120 / 120 / 120` |
| 二等測 | `20.70` | `19.47` | `0.94 / 0.94 / 0.47` | `97 / 131 / 131` |
| 不等測 | `55` | `45` | `0.82 / 0.71 / 0.91` | `135 / 116 / 108` |

二等測は x軸とy軸の縮み率が等しく z軸だけがその半分になる向き（`1 : 1 : 1/2`）。

### パネル

`プリセットへ合わせる`（リスト）／`方位角`（`5`〜`85`度）／`仰角`（`5`〜`80`度）／`縮み率（x / y / z）`・`軸のなす角（xy / yz / zx）`・`種類`（読み取り専用）。

プリセットは「飛ぶだけの操作」で、スライダーを動かしても選択は残る。いま実際にどの種類かは `種類` の欄が示す。

## 案5：斜投影（カバリエ図とキャビネット図）（実装済み）

| | |
| --- | --- |
| ディレクトリ | `app/src/lib/demo/threejs/transformation/parallel-projection-types/oblique/` |
| 公開関数 | `createObliqueScene` |
| 挿入位置 | 「斜投影」節の `:::Todo` と差し替え |

- 前面を投影面に接した立方体と、投影面に斜めに交わる投射線
- 前面は正方形のまま実寸で写り、奥行き方向の辺だけが斜めに伸びる

案3+4と同じ左右2面構成にした。左「立方体と投影面」に、投影面（`xy` 平面）へ面を接した立方体・`3`本の座標軸・斜めの投射線・投影面に写った像を置き、右「投影面に写った像」にその像を正面から見たものと、縮まなかったときの軸の先を示す円を描く。

### 実装の要点

**立方体は投影面に接した面の中心を原点に置き、`z` の正の側（奥行き方向）へ伸ばす。** 座標軸が面の内側を通るので、案3+4のように軸と重なる稜線を外す必要がない。

- 像は `(x + z·L·cos α, y + z·L·sin α)`。`z = 0` の面がずれを受けないことが「接した面が実寸で写る」に対応する
- **投影面に接した面の稜線は形状の側では描かず、像（`IMAGE_COLOR`）に任せる。** 完全に重なるので二重に描かない
- 軸の像は倍率 `0` で点に潰れるため、`setTip` で長さ `0` のときは矢印と軸名を隠す（向きを正規化できない）

### パネル

`プリセットへ合わせる`（カバリエ図／キャビネット図）／`奥行きの倍率`（`0`〜`1`、刻み `0.01`）／`奥行きの向き`（`15`〜`75`度、刻み `1`）／`投射線が投影面となす角`（読み取り専用）／`スキューさせた形状を重ねる`（**既定オフ**）。

初期値はカバリエ図（倍率 `1`・向き `45`度）。

- **プリセットは仕様になかったが追加した。** カバリエ図・キャビネット図という呼び名と倍率の対応を示すため。案3+4と同じ一方向（プリセット→スライダーの `refresh()`）
- **`投射線が投影面となす角` も追加した**（`atan(1 / 倍率)`）。本文の「この角が`45`度のとき、辺は実際の長さのまま写ります」を確かめられるようにするため。倍率 `0` では `90`度になり、直投影に戻ることも読める

### 注意点

`スキューさせた形状を重ねる` を既定オフにするのは、対応する本文（「形状を奥行き方向にスキューさせてから直投影しても、同じ像が得られる」）が挿入位置より**後の段落**にあるため。先取りを避ける。**`:::Action` でもこのトグルには触れない。**

同じ理由で、**掲載コードからもスキューの部分を外した**（掲載コードは初期表示＝トグルオフの絵に合わせる規約にも沿う）。トグルを入れると、スキューさせた形状（`#c792ea`）と、そこから投影面へ垂直に下ろした投射線が現れ、斜投影の投射線と同じ`4`点に届く。
